# POC legada — modelo inicial em inglês

Esta pasta isola os artefatos históricos da prova de conceito inicial do
LabVet. Ela inclui o schema em inglês, scripts de importação, consultas,
diagramas e a demonstração offline produzidos antes da definição da base
oficial Labvet V1.

Esse conteúdo é somente referência histórica. Não deve ser usado por:

- migrations em `database/estrutura`;
- models, repositories, services ou controllers do backend atual;
- contratos HTTP ou telas do aplicativo oficial;
- inicialização automática do PostgreSQL.

O produto ativo usa exclusivamente o modelo oficial documentado em
`docs/BASES_DE_DADOS.md` e os scripts de `database/estrutura`.
